# Compose Craft

## Theme
- `CaffeineTheme` provides a `CaffeineColors` object (every `night/*` token, Dark and Light) through a `CompositionLocal`, plus a Material 3 `ColorScheme` mapped from it so stock components look right. **Dynamic color is off**: Caffeine is a brand palette.
- Light/Dark follows the in-app Theme setting (System / Light / Dark), defaulting to system.
- Spacing and radii come from `CaffeineDimens` (`space/0..64`, `radius/sm..full`), generated by `ux-ui-designer`. No raw `dp` in feature code.
- Typography: `CaffeineType` maps each `iOS/*` and `Data/*` style to an `sp` TextStyle (see `design-tokens`). Use `sp` so system font scale works.

## Translating iOS-native patterns
| Figma / iOS | Android |
|---|---|
| Large Title nav + back "‹ Home" | `LargeTopAppBar` with up arrow; system back gesture |
| Bottom sheet with grabber | `ModalBottomSheet` |
| Glass material (`Material/Glass`) | `surface-raised` / `glass-*` token fill + 1dp `glass-stroke`; real blur only on API 31+ (`Modifier.blur` / RenderEffect), solid fallback below |
| Tab bar + coral + | `NavigationBar` with a custom centre FAB slot; same order Home · Wallet · Analytics · Profile |
| SF Symbols | Material Symbols Rounded equivalents, listed per screen in the design spec |
| Haptics | `HapticFeedbackConstants` via `LocalView` |

## Components
Extract to `shared/components/` on the second use. Shared composables take simple parameters, not feature State. Mirror the iOS shared component names (`BudgetHero`, `MetricHero`, `LedgerRow`, `QuickActionTile`...).

## Motion
Spring specs for user-driven motion; 150–200 ms micro, 300–400 ms list changes; ease-out `CubicBezierEasing(0.22f, 1f, 0.36f, 1f)` to match the prototype. Respect reduced motion (animator duration scale 0 → final state).

## Accessibility and test ids
- Every interactive element: `contentDescription`/semantics label and `Modifier.testTag("<screen>.<element>")`, with `testTagsAsResourceId = true` at the root, so Appium ids match iOS.
- Minimum touch target 48dp. Content descriptions say the signed amount ("minus 320 baht").

## Edge-to-edge
`enableEdgeToEdge()`; handle insets with `WindowInsets.safeDrawing`. Bottom-pinned elements sit 40dp above the navigation inset, as on iOS.
